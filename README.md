# CodeNova Student Project Showcase

## About the Project

A web-based Student Project Showcase developed for the CodeNova Full Stack Development Internship – Batch 01.

The application allows students to submit their projects and enables administrators to review, approve, reject, and delete submissions.

## Features

- Student project submission
- Project title, description, and technology details
- Project category selection
- SQLite database storage
- Admin dashboard
- Approve and reject project submissions
- Display approved projects on the homepage
- Responsive website design

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install the required dependencies.
4. Run the Flask application.

```bash
pip install -r requirements.txt
python app.py
```

5. Open `http://127.0.0.1:5000` in your browser.

## Admin Dashboard

Open `http://127.0.0.1:5000/admin` to manage project submissions.
